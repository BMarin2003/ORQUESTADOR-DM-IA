# sustentacion

| Carpeta o archivo | Contenido |
| --- | --- |
| **`Sustentacion_UPAO.pptx`** | **Deck oficial**, en el formato de la plantilla UPAO, con notas del orador |
| [`formato_oficial/`](formato_oficial/) | Plantilla oficial de referencia (REP_ICSI) |
| `CONTEXTO_SUSTENTACION.md` | Fuente de verdad de cifras, reglas y preguntas probables del jurado |
| [`propuestas/`](propuestas/) | Decks anteriores: v1 y v2 (con `material_v2/`), v3 (exposición de 15 min) y v4 (enfoque metodológico con analogías) |
| [`generador/`](generador/) | `deck_upao.py` (oficial), `deck.js` (v3) y `deck_v4.js` (v4) |
| [`guiones/`](guiones/) | Guiones de explicación de los cierres de brecha |

Regenerar el deck oficial: `python sustentacion/generador/deck_upao.py` (requiere `python-pptx`).
